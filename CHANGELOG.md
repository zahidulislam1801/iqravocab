# Changelog

All notable changes to IQRA VOCAB. Newest first.

## 2026-10-30

### Added
- Website sidebar: "Get the app" with direct Android and Windows downloads, showing size and date.
- Android app sidebar: "App updates" with an automatic check every 3 days, a Check for updates button, a red dot on the menu button and an Update now button that downloads and opens the installer.
- `sw.js` service worker: faster repeat opens and offline use.
- `README.md`, `404.html`, `.nojekyll`, `favicon.ico`.
- `og-image.png` and share-preview meta tags in `index.html`.
- `.github/workflows/validate.yml`: checks scripts, data blocks and required files after each upload.

### Removed
- Three dead code blocks that could never run: the old review-invitation schedule, the old cloud-save start-up code, and a disabled button shine effect.

### Unchanged
- All word, question and example data, and every embedded font and image.
